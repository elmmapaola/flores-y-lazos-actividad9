# Flores y Lazos

## Actividad 9: Sitio web interactivo con un plugin de jQuery

Autora: Elmma Paola Borrego Santiago
Materia: Programación para Internet
Universidad: Universidad Anáhuac Querétaro

## Descripción

Sitio web de una florería ficticia con cuatro secciones:
Inicio, Nosotros, Productos y Contacto.

## Estructura

- index.html: estructura y contenido del sitio.
- css/estilos.css: identidad visual y diseño responsivo.
- js/principal.js: JavaScript, jQuery e inicialización del plugin.
- README.md: documentación del proyecto.

## Tecnologías

- HTML5.
- CSS3.
- JavaScript.
- jQuery 3.7.1.
- bxSlider 4.2.17.
- Google Maps mediante iframe.

## Funciones de JavaScript

1. Fecha y hora actual, actualizadas cada segundo.
2. Validación del formulario.
3. Botón Ir arriba.
4. Cotizador de arreglos.
5. Menú para dispositivos móviles.
6. Contador de caracteres del mensaje.

## Funciones de jQuery

- Eventos click mediante on().
- Filtro de productos con fadeIn().
- Preguntas frecuentes con slideToggle().
- Favoritos con append() y remove().
- Actualización de clases, atributos y textos.

## Plugin

bxSlider se utiliza para mostrar tres imágenes
en un carrusel con flechas y paginación.

## Ejecución

Abrir index.html en un navegador actualizado
o utilizar Live Server desde VS Code.

Se requiere conexión a internet para cargar
las fotografías, jQuery, bxSlider y Google Maps.
